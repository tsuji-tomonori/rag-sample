# Post-task fit report

Append to `reports/working/YYYYMMDD-HHMM-<summary>.md` during work. Include instructions,
requirements, decisions, commands and actual outcomes, artifacts, instruction fit, unresolved risks,
external blockers, and skipped checks. Never rewrite a failure as a pass or treat a partial milestone
as completion of the persistent goal.
